# Справочник по данным

Документ описывает: какие файлы раздают организаторы, как их читать, что означают теги и показатели, как правильно синхронизировать источники. Обязательное чтение перед началом работы с данными.

## Карта источников

Все исходники хакатона лежат в общем хранилище команды (в git не коммитятся). Локально принято класть в папку `hackathon/` в корне проекта - именно этот путь используется в конфигурации и путях по умолчанию.

| Файл | Что внутри | Формат |
|---|---|---|
| `data/avt_tags.csv` | Телеметрия АВТ, 74 датчика | CSV, 10-мин ряды |
| `data/242000_tags.csv` | Телеметрия гидроочистки (24-2000), 28 датчиков | CSV, 10-мин ряды |
| `Выгрузка ПАК 01.01.2023 - н.в_.xlsx` | Поточные анализаторы: сера, D15 | XLSX, 10-мин ряды |
| `ЛИМСы 01.01.2023 - н.в_ (2).xlsx` | Лабораторные анализы качества | XLSX, редкий и асинхронный |
| `Теги_хакатон.xlsx` | Справочник тегов + формулы виртуальных анализаторов | XLSX, 4 листа |
| `АВТ_схемы.pdf` | Технологические схемы установок | PDF |
| `ТЗ_нефтекод.docx` | Исходное ТЗ хакатона | DOCX |

Пути в таблице даны относительно корня папки хакатона.

Временной диапазон всех временных рядов: 2023-01-01 до 2026-08-07 (10-мин срезы, около 189 тысяч точек).

## Как читать XLSX-файлы

### `Теги_хакатон.xlsx` (справочник)

Четыре листа. Читаются напрямую `pd.read_excel(sheet_name=...)`.

**Лист `КИП`.** Расшифровка тегов телеметрии. Формат: пары колонок `[описание, короткое имя]` для двух установок.

| АВТ (описание) | АВТ | 24-2000 (описание) | 24-2000 |
|---|---|---|---|
| Температура верха К1. Выход на FIRC0955 | T1 | Расход бензина c установки | F1 |
| Давление бензиновых паров верха К1 | P2 | Газовая схема. Расход на линии от ЦК-201 | F2 |
| ... | ... | ... | ... |

Короткие имена (`T1`, `P2`, `F3`, `T55`, `F30` и т.д.) - это заголовки колонок в CSV-файлах телеметрии. Первая буква обозначает тип измерения:

- `T` - температура (°C).
- `P` - давление или вакуум.
- `F` - объёмный расход.
- `W` - массовый расход (т/ч).
- `L` - уровень (%).
- `D` - плотность (кг/м³).

**Лист `ЛА`.** Матрица «точка отбора × измеряемый показатель». Столбец = точка отбора (пример заголовка: `Установка 'АВТ'. Точка отбора '2'. Продукт 'Дизельное топливо'`). Значения ячеек - названия показателей, которые в этой точке меряются в лаборатории.

Используется для ответа на вопросы «где меряется T50 дизеля» и «какие показатели вообще существуют по каждой точке».

**Лист `ПАК`.** Список поточных анализаторов. Два анализатора: сера в гидроочищенном ДТ (`24-2000:Mg.Sulfur.Q`) и расчётная плотность (`24-2000:D15`).

**Лист `ВАК`.** Виртуальные анализаторы - готовые формулы для расчёта показателей качества по тегам телеметрии. Формат: пары колонок `[имя показателя, формула]`. Пример:

```
AVT6:240-350:T50 = 283.177 + F7*(-0.01685) + 0.06248*F30 + 0.22048*F34 - ...
```

Формулы используются как база (baseline) для ML-моделей качества. Значения фичей в формулах - те же короткие имена тегов, что и на листе КИП.

### `data/avt_tags.csv` и `data/242000_tags.csv` (телеметрия)

Плоский CSV, читается `pd.read_csv`. Формат:

| Unnamed: 0.1 | Unnamed: 0 | date | T1 | P2 | F3 | ... |
|---|---|---|---|---|---|---|
| 0 | 0 | 2023-01-01 00:00:00 | 123.4 | 3.54 | 68.6 | ... |

Ключ времени - колонка `date`. Колонки `Unnamed: *` - служебные, при загрузке удаляются. Все прочие колонки - значения тегов, названия соответствуют короткому имени из справочника КИП.

Ряды синхронные, шаг 10 минут, пропуски встречаются. Файлы `avt_tags.csv` и `242000_tags.csv` имеют одинаковую сетку времени - можно джойнить прямо по `date`.

### `Выгрузка ПАК ...xlsx` (поточные анализаторы)

XLSX с одним листом. Многоуровневая шапка: **пары колонок на каждый анализатор** (timestamp, value). Итого 5 колонок:

| строка | col 0 | col 1 | col 2 | col 3 | col 4 |
|---|---|---|---|---|---|
| 0 (шапка) | `24-2000:Mg.Sulfur` | - | - | `24-2000:D15` | - |
| 1 (единица) | `ppm` | - | - | `кг/м3` | - |
| 2 | 2023-01-01 00:00:00 | 6.57 | - | 2025-03-05 10:20:00 | 831.51 |
| 3 | 2023-01-01 00:10:00 | 6.73 | - | 2025-03-05 10:30:00 | 831.33 |

Правила чтения:
- Читается через `pd.read_excel(header=None, skiprows=2)`.
- Между парами колонок есть пустая колонка-разделитель (col 2 в примере).
- **Даты у анализаторов не совпадают**: сера начинается с 2023-01-01, D15 - только с 2025-03-05. Каждый анализатор обрабатывается независимо.
- После загрузки каждый анализатор превращается в отдельный `DataFrame` с колонками `[date, value]`, потом клеится к общей шкале.

### `ЛИМСы ...xlsx` (лабораторные анализы)

Самый сложный файл. Один лист, 108 колонок, многоуровневая шапка. Разметка выглядит так:

| строка | col 0 | col 1 | col 2 | col 3 | ... |
|---|---|---|---|---|---|
| 0 (блок) | `Установка 'АВТ'. Точка отбора '1'. Продукт 'Дизельное топливо'` | - | - | - | ... |
| 1 (показатель) | `CFPP` | - | `90%.T` | - | ... |
| 2 (единица) | `°С` | - | `°С` | - | ... |
| 3 (мета) | - | `Количество значений: 44` | - | `Количество значений: 580` | ... |
| 4+ (данные) | 2025-10-17 08:00:00 | 1 | 2023-01-02 14:00:00 | 344 | ... |

Правила чтения:
- Каждый показатель занимает **две колонки**: чётная - timestamp измерения, нечётная - значение.
- Заголовок блока (строка 0) появляется только в первой колонке блока и относится ко всем показателям блока, пока не встретится следующий заголовок.
- Между собой измерения разных показателей **асинхронные**: разные даты, разное количество точек.
- Читается через `pd.read_excel(header=None)`, дальше вручную распарсивается: 
  1. По строкам 0-2 собирается словарь `col_index -> {block, indicator, unit}`.
  2. Каждая пара колонок разворачивается в отдельный `DataFrame` `[date, value, indicator, sampling_point]`.
  3. Всё склеивается вертикально в «длинную» таблицу.

Ключевое: **никакого выравнивания по номеру строки**. Строки не связаны между собой, даты в соседних колонках не совпадают.

### `АВТ_схемы.pdf` и `ТЗ_нефтекод.docx`

Читаются человеком, для контекста процесса. Схема нужна, чтобы понимать физику установки и выбирать управляемые теги. ТЗ - исходное задание хакатона.

## Показатели качества

Все показатели меряются в лаборатории (ЛИМС), часть также рассчитывается поточно (ПАК) или расчётно (ВАК).

| Обозначение | Физический смысл | Единица |
|---|---|---|
| Сера (`Mg.Sulfur`, `sulfur`) | Содержание серы в топливе. Жёсткая спека для товарного ДТ: не более 10 мг/кг. | мг/кг (ppm) |
| `T50`, `50%.T` | Температура, при которой отгоняется 50% пробы. Характеристика фракционного состава. | °C |
| `T90`, `90%.T` | То же для 90%. | °C |
| `EBP.T` | End Boiling Point, температура конца кипения. | °C |
| `D15`, `Плотность при 15°С` | Плотность топлива при 15°C. | кг/м³ |
| `CFPP`, `ПТФ` | Cold Filter Plugging Point, предельная температура фильтруемости. Критично для зимнего дизеля. | °C |
| `PourPoint` | Температура застывания. | °C |
| `Т помутнения`, `CloudPoint` | Температура помутнения. | °C |
| `Вспышка` | Температура вспышки. | °C |
| `ТНК` | Температура начала кипения. | °C |

По одному и тому же показателю (например `T50`) могут существовать разные значения для разных **фракций** и разных **точек отбора**. `T50` фракции 240-350 и `T50` фракции 350-500 - это разные величины, не путать.

## Приоритет источников качества

При расхождении значений действует правило:

**ЛИМС > ПАК > расчётные ВАК**

- ЛИМС - лабораторный эталон, самая высокая точность, но самая низкая частота.
- ПАК - поточный анализ, шаг 10 минут, средняя точность, может дрейфовать.
- ВАК - расчётная зависимость на телеметрии, доступна всегда, но зависит от адекватности формулы.

При построении моделей: таргет - ЛИМС там, где данных достаточно, ПАК - для главных таргетов с частым обновлением (в первую очередь сера). ВАК - как физический прайер / фича / baseline.

## Синхронизация по времени

Три правила, обязательные к соблюдению.

1. **Только по метке времени.** Ни один источник не выравнивается по номеру строки. Все ряды имеют собственную сетку времени (даже в пределах ЛИМС разные показатели измеряются в разное время).
2. **Возраст лабораторного значения - обязательная фича.** Для каждой точки отбора и показателя ЛИМС трекается `lims_age_hours` - сколько часов прошло с момента последнего измерения. Значение старше 24 часов должно приводить к снижению confidence в прогнозе.
3. **Никакой утечки будущего.** Для прогноза на момент T допустимо использовать только данные с меткой `date <= T`. Проверяется автотестами в `backend/ml/validation/`.

Технически синхронизация делается через `pd.merge_asof`:
- Основа - сетка телеметрии (10-мин шаг).
- К ней клеится ПАК тоже через 10-мин выравнивание.
- ЛИМС клеится через `merge_asof(direction="backward")`: для каждой строки берётся последнее лабораторное значение слева по времени, вместе с его возрастом.

## Задержки между стадиями

Стадии производства физически разнесены во времени. Продукт с АВТ доезжает до гидроочистки через промежуточный резервуар. Между стадиями есть задержка порядка часов.

Из этого следует:
- Изменение параметра на АВТ **не мгновенно** влияет на серу в гидроочистке.
- Для модели гидроочистки признаки АВТ должны быть **сдвинуты назад по времени** на эмпирически определённую задержку.
- Задержка определяется через кросс-корреляцию: сдвигаем ряд с АВТ на разное количество шагов, ищем максимум корреляции с серой на гидроочистке.

## Единицы измерения

Основные единицы, встречающиеся в данных:

| Величина | Единица | Комментарий |
|---|---|---|
| Температура | °C | Иногда встречается °К в формулах ВАК. Проверять контекст. |
| Давление | атм, кгс/см² | В некоторых тегах вакуум приводится к мм рт.ст. отдельным пересчётом. |
| Расход объёмный | м³/ч | |
| Расход массовый | т/ч | Обозначается буквой `W` в имени тега. |
| Плотность | кг/м³ | |
| Сера | ppm (мг/кг) | |
| Уровень | % | В долях от полного объёма. |

При смене единицы в источнике конвертация описывается явно в feature registry.

## Известные подводные камни

1. **Колонки `Unnamed: *` в CSV.** Служебные индексы pandas, всегда удаляются при загрузке.
2. **Пустая колонка-разделитель в ПАК.** Между парами анализаторов идёт пустая колонка. При наивном чтении её надо явно пропустить.
3. **Заголовок блока в ЛИМС появляется один раз.** При парсинге нужно «протаскивать» его вправо до следующего заголовка.
4. **Одинаковые названия показателей у разных фракций.** T50 фракции 240-350 и T50 фракции 350-500 - это две разные колонки, различаются только по блоку. Всегда клеить показатель с меткой источника (точка отбора).
5. **Разное покрытие ПАК.** Сера с 2023 года, D15 - только с марта 2025. Не считать, что «отсутствие значения» == «поломка датчика».
6. **Даты и типы.** В CSV метка времени приходит строкой, обязательно приводить к `datetime` с указанием формата, иначе pandas догадывается медленно и криво.
7. **Формулы ВАК содержат кириллические буквы `х` вместо латинских `*`.** Пример: `791,22872 - 5,30294x(F30/(F32+ F30))`. При автоматическом парсинге формул это заменяется на `*`, десятичные запятые - на точки.
8. **Дрейф калибровки ПАК.** ПАК не всегда точно совпадает с ЛИМС. При использовании ПАК как таргета имеет смысл периодически калибровать модель по ЛИМС.

## Feature Registry

Итоговый выход всей работы с данными - файл `backend/data_layer/feature_registry.yaml`. Формат:

```yaml
T55:
  source: hackathon/data/avt_tags.csv
  unit: C
  description: Температура на выходе из печи П3
  controllable: true
  range_min: 340
  range_max: 370
  role: feature

sulfur_hydro:
  source: hackathon/Выгрузка ПАК 01.01.2023 - н.в_.xlsx
  column: 24-2000:Mg.Sulfur
  unit: ppm
  role: target
  spec_max: 10
```

Реестр - единый source of truth. Все компоненты (ML, агенты, оптимизатор) читают границы, единицы и роли фичей отсюда.

## Проверочные вопросы

Быстрый чек, что данные поняты правильно:
- Где меряется сера, которую мы прогнозируем? (Ответ: поточный анализатор `24-2000:Mg.Sulfur`, файл `Выгрузка ПАК`, шаг 10 минут.)
- Что означает тег `T55`? (Ответ: смотреть лист КИП справочника. Это температура на выходе из печи П3.)
- Как узнать, какие показатели меряются в точке отбора 2 на АВТ? (Ответ: лист ЛА справочника, столбец «Установка 'АВТ'. Точка отбора '2'».)
- Можно ли для прогноза на 2024-05-15 12:00 использовать значение ЛИМС от 2024-05-15 14:00? (Ответ: нет, это утечка будущего.)
- Что делать, если ПАК показывает серу 8 ppm, а ЛИМС - 12 ppm за то же время? (Ответ: ЛИМС - эталон, использовать его, ПАК считать дрейфующим.)
