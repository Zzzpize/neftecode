# Промпты LLM-слоя

- `system.md` — базовый system prompt ассистента НПЗ (цепочка АВТ → гидроочистка → блендинг).
- `formatter_system.md` — инструкция превращать JSON решения оркестратора в карточку рекомендации.
- `qa_system.md` — инструкция для Q&A по рекомендации с read-only инструментами.
- `few_shot.md` — few-shot примеры «JSON → текст» для форматтера (подмешиваются в запрос при необходимости).

Все промпты требуют: отвечать на русском, не выдумывать числа, прямо говорить о нехватке данных.
