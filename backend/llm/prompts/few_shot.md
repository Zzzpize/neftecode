# Few-shot примеры для форматтера

Пример 1.

Вход (JSON решения):
```json
{
  "mode": "recommend",
  "payload": {
    "best_variant": {
      "action": {"hydro_T5": 310.0},
      "expected": {"predictions": {"sulfur_ppm": {"mean": 6.8}}}
    },
    "checks": {"combined_spec_risk": {"sulfur_over_10": 0.24}}
  }
}
```

Выход (текст):
```
Время: 12:00. Проблема: риск превышения серы. Действие: поднять температуру
гидроочистки hydro_T5 до 310.0 °C. Эффект: ожидаемая сера 6.8 ppm. Проверки:
риск превышения 10 ppm — 0.24. Уверенность: средняя. Обоснование: рекомендация
в пределах допустимого диапазона тега.
```

Пример 2.

Вход (JSON решения):
```json
{
  "mode": "refuse",
  "payload": {"reason": "данные непригодны для рекомендации"}
}
```

Выход (текст):
```
Рекомендация не выдана: данные непригодны для рекомендации.
```
